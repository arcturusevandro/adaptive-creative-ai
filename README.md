# Adaptive Creative AI

Projeto de aprendizado e portfólio iniciado do zero para desenvolver, testar e documentar soluções práticas envolvendo Inteligência Artificial aplicada a fluxos criativos e automação.

## Princípio do projeto

O desenvolvimento será registrado progressivamente no GitHub. O histórico deve representar a evolução real do projeto, desde requisitos e experimentos iniciais até implementações, testes e decisões técnicas.

## Método

**problema -> requisitos -> arquitetura -> implementação -> teste -> validação -> documentação -> melhoria**

## Regras de evolução

- não fabricar histórico retroativo;
- documentar decisões técnicas relevantes;
- separar protótipos de funcionalidades validadas;
- testar antes de declarar uma funcionalidade concluída;
- nunca publicar credenciais, tokens ou dados confidenciais;
- aproveitar Skills/Plugins e boas práticas oficiais aplicáveis antes de criar processos redundantes;
- preservar evidências reais da evolução para fins de aprendizado e portfólio.

## Status

Repositório inicial. Arquitetura, escopo e primeiro caso prático ainda serão definidos e documentados conforme o projeto evoluir.
